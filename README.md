# CustomBunnyColor
Super Bunny Man mod that changes the color of the bunny suit to the desired one, F2 to toggle the menu

## Prerequisites

* **BepInEx 5** (Unity Mono version) installed in your *Super Bunny Man* root directory.

---

## Installation

1. Go to the **Releases** section on the right side of this repository.
2. Download `CustomBunnyColor.zip`.
3. Extract `CustomBunnyColor.dll` into your game's `BepInEx/plugins/` folder.
